# Disk Scan — ดูว่าอะไรกินพื้นที่ในไดร์ฟ

โปรแกรมสแกนทั้งไดร์ฟ แล้วบอกว่าโฟลเดอร์และไฟล์ไหนใช้พื้นที่มากที่สุด

## วิธีใช้
1. ดับเบิลคลิกไฟล์ `DiskScan.exe` (ไม่ต้องติดตั้งอะไร ใช้ได้กับ Windows 10/11)
2. (แนะนำ) กดปุ่ม **รันแบบ Admin** ที่มุมขวาบนก่อน จะได้สแกนโฟลเดอร์ระบบที่ถูกล็อกสิทธิ์ได้ครบ
3. คลิกที่การ์ดของไดร์ฟที่ต้องการ (เช่น C:) แล้วรอสักครู่จนสแกนเสร็จ
4. ดูผลได้ 3 แบบ
   - **โฟลเดอร์**: เรียงจากใหญ่ไปเล็ก ดับเบิลคลิกเพื่อเข้าไปดูข้างใน กด **ย้อนกลับ** เพื่อกลับขึ้นไป
   - **ไฟล์ใหญ่ที่สุด**: 1000 ไฟล์ที่ใหญ่ที่สุดในไดร์ฟ
   - **แยกตามชนิดไฟล์**: ขนาดรวมของไฟล์แต่ละนามสกุล เช่น .mp4 หรือ .iso
5. คลิกรายการที่ต้องการ แล้วกด **คัดลอก Path** (หรือกด Ctrl+C หรือคลิกขวา) จะได้ Path ไปวางที่อื่น
   หรือกด **เปิดใน Explorer** เพื่อไปที่ตำแหน่งนั้น

## สีของรายการ
| สี | ความหมาย |
|---|---|
| 🔴 แดง [ห้ามลบ] | ไฟล์ระบบ Windows **ห้ามลบเด็ดขาด** (Windows, pagefile.sys, hiberfil.sys, System Volume Information ฯลฯ) |
| 🟠 ส้ม [ระวัง] | โปรแกรมที่ติดตั้งไว้หรือข้อมูลของโปรแกรม ถ้าไม่ใช้ให้ Uninstall แทนการลบโฟลเดอร์ |
| 🟢 เขียว [ล้างได้] | ล้างได้ตามวิธีที่แนะนำ (Temp, Recycle Bin, Downloads) |

คลิกที่รายการใดก็ได้ ด้านล่างจะบอกคำแนะนำว่าควรจัดการกับรายการนั้นอย่างไร

> ⚠ โปรแกรมนี้แค่ **แสดงผลอย่างเดียว ไม่ลบไฟล์ใดๆ** ถ้าจะลบอะไร ให้ตรวจสอบให้แน่ใจก่อน และลบแบบลงถังขยะไว้ เผื่ออยากกู้คืน

## หมายเหตุ
- ขนาดของ `C:\Windows\WinSxS` อาจดูใหญ่เกินจริง เพราะไฟล์บางส่วนใช้ร่วมกับ System32 (hard link)
- ไฟล์ OneDrive ที่อยู่บนคลาวด์อย่างเดียว (online-only) ไม่ได้ใช้พื้นที่ในเครื่อง จึงนับเป็น 0
- ไม่สแกนเข้าไปใน junction หรือ symlink เพื่อไม่ให้นับไฟล์เดียวกันซ้ำ

## Build เอง (สำหรับนักพัฒนา)
ซอร์สโค้ดอยู่ที่ `src/Program.cs` (C# WinForms) ดับเบิลคลิก `build.bat` ก็จะได้ `DiskScan.exe`
โดยใช้คอมไพเลอร์ C# ที่มากับ Windows อยู่แล้ว ไม่ต้องติดตั้ง Visual Studio
